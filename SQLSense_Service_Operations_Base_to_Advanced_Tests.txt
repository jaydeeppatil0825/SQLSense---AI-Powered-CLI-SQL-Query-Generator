===============================================================================
SQLSENSE SERVICE OPERATIONS LAB — BASE TO ADVANCED TEST SET
===============================================================================

DATABASE
sqlsense_service_operations_lab

PURPOSE
Test every currently implemented deterministic SQLSense capability, from basic
single-table questions through direct joins, direct joined aggregates, date
logic, and Phase 7 two-edge multi-hop joined lookup.

CURRENT SUPPORTED JOIN SCOPE
- Direct lookup: 2 tables / 1 safe Relationship Graph edge
- Direct joined aggregate: 2 tables / 1 safe Relationship Graph edge
- Multi-hop lookup: 3 tables / exactly 2 safe ordered edges
- Multi-hop aggregate: intentionally blocked
- No bridge planning, no 3+ edge paths, no runtime AI

RELATIONSHIP GRAPH
- customers.region_id -> regions.region_id
- technicians.region_id -> regions.region_id
- parts.supplier_id -> suppliers.supplier_id
- service_orders.customer_id -> customers.customer_id
- service_orders.technician_id -> technicians.technician_id
- service_items.service_order_id -> service_orders.service_order_id
- service_items.part_id -> parts.part_id
- invoices.service_order_id -> service_orders.service_order_id
- payments.invoice_id -> invoices.invoice_id

===============================================================================
ACCEPTANCE SUMMARY
===============================================================================

Expected supported:
- Basic lists and counts
- Filters and numeric comparisons
- Single-table SUM/AVG/COUNT/MIN/MAX
- GROUP BY, HAVING, ranking, LIMIT
- Direct 1-edge joined lookup
- Direct 1-edge joined aggregates
- Deterministic date intervals
- Phase 7 unique linear 2-edge joined lookup
- Filters on any table in the selected 2-edge path

Expected fail-closed:
- Multi-hop aggregates
- 3+ edge paths
- Branching/fan-out joins
- Ambiguous equal paths
- Unsafe commands
- Non-numeric aggregate metrics
- Ambiguous metric/dimension ownership

Recommended result columns:
Test ID | Question | Capability | Expected Route | Expected Shape |
Expected Path | Expected SQL Pattern | Actual Route | Actual Shape |
Actual SQL | Rows | PASS/FAIL
